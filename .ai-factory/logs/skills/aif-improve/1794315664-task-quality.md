# E2: уточнены задачи 17, 21, 23

**Date:** 2026-11-10 13:01
**Plan:** .ai-factory/plans/feature-e2-observability.md
**Severity:** low

## Problem

Задача 21 не задавала окружение и уборку дочернего процесса потребителя; задача 17 не снимала обработчики сигналов; задача 23 двусмысленно говорила о git status в чужих репозиториях

## Root Cause

План описывал случаи теста, но не стенд процесса и глобальные обработчики

## Solution

Добавлены env ребёнка из inject('kitPostgresUrl'), SIGKILL в afterEach, снятие обработчиков сигналов, ясная формулировка только-чтения

## Prevention

Для тестов с дочерними процессами и process-глобальными обработчиками описывать стенд и уборку
