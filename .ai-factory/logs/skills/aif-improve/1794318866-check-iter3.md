# E2 +check итерация 3: тип genReqId и порядок восстановления таймеров

**Date:** 2026-11-10 13:54
**Plan:** .ai-factory/plans/feature-e2-observability.md
**Severity:** medium

## Problem

GenReqId pino-http не присваивается genReqId Fastify (TS2322); restoreMocks после useRealTimers возвращает фейковый setTimeout

## Root Cause

Типы кортежа выведены без проверки совместимости с адаптером; не учтён порядок автоматического restoreMocks Vitest

## Solution

KitLoggerParams сужает genReqId до (req) => string, проверка в types-check потребителя; afterEach: restoreAllMocks, затем useRealTimers

## Prevention

Компилировать спорные типовые выражения на установленных пакетах; учитывать хуки Vitest при шпионах поверх фейковых таймеров
