# E2 +check итерация 4: неверный SENTRY_DSN печатается SDK и включает Sentry

**Date:** 2026-11-10 14:02
**Plan:** .ai-factory/plans/feature-e2-observability.md
**Severity:** high

## Problem

initSentry отсекал только пустой DSN; @sentry/core печатает Invalid Sentry Dsn: <значение> через console.error и создаёт клиента без DSN; тест под моком этого не ловил

## Root Cause

Поведение SDK при неверном значении не проверено на установленной версии

## Solution

Проверка формы DSN до Sentry.init; тест AC-2.4 с моком и на настоящем SDK со шпионами console.error и stderr

## Prevention

Проверять, что внешний SDK делает с неверным вводом (вывод, побочные эффекты), а не только что не бросает
