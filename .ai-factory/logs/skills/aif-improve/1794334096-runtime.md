# Keep-alive при остановке, экспорт ядра, путь к построителю OpenAPI

**Date:** 2026-11-10 18:08
**Plan:** .ai-factory/plans/feature-e3-http-framework.md
**Severity:** high

## Problem

closeServer зависал на keep-alive соединениях до 72 с; глобальный KitHttpCoreModule без exports; CLI грузил внутренний buildOpenApiDocument из index.ts

## Root Cause

Поведение Node http при close не проверено запуском; правило видимости глобального модуля Nest упущено

## Solution

Connection: close и closeIdleConnections в onResponse при closing; exports ядра; импорт ../../http/api/openapi-document.js; новые U-случаи

## Prevention

Сценарии остановки проверять запуском с keep-alive клиентом; у глобальных модулей перечислять exports
