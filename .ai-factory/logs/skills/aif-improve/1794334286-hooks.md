# Место регистрации хуков остановки, закрытие SSE, строка cli в ARCHITECTURE

**Date:** 2026-11-10 18:11
**Plan:** .ai-factory/plans/feature-e3-http-framework.md
**Severity:** medium

## Problem

Не сказано, что хуки onSend/onResponse регистрируются до init (addHook после listen бросает); не сказано, как участник SSE закрывает поток; ARCHITECTURE не разрешает CLI внутренний модуль http/api

## Root Cause

Правка keep-alive описала механизм, но не время регистрации и контракт участника

## Solution

Хуки до app.init() с флагом closing; участник SSE вызывает reply.raw.end()/destroy(); строка cli в задаче 22

## Prevention

Для хуков фреймворка указывать момент регистрации; для участников — точный контракт завершения
