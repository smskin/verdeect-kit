# Итерация 4 +check: тесты, падающие при верном коде

**Date:** 2026-11-11 09:09
**Plan:** .ai-factory/plans/feature-e5-messaging
**Severity:** high

## Problem

AC-4.12 читал настройки из пула чтения; ac-4-14 терял результат countQueries; AC-5.16 смешивал паузы с ожиданием подтверждения; сигнал очистки срабатывал на запросы relay; vitest на верхнем уровне ломал импорт /testing без vitest; имя 'x' не проходит формат

## Root Cause

Тесты описаны без сверки пулов, общих таймеров, общего пула запросов и формата имени

## Solution

Чтение с основного пула; queries из countQueries; kind у RelayTimers.sleep; сигнал по delete-SQL; vitest внутри функций и мягкий импорт в worker-scope; peer-check

## Prevention

Для теста проверять, на каком ресурсе выполняется утверждение и кто ещё пишет в тот же ресурс
