# Итерация 5 +check: контракты помощников и гонка relay потребителя

**Date:** 2026-11-11 09:15
**Plan:** .ai-factory/plans/feature-e5-messaging
**Severity:** high

## Problem

RabbitAdmin.queue без полей, нужных AC-5.9/5.17; prepareWorkerVhosts/deleteTestVhosts и строка teardown не определены в T11; сравнение политики outbox не совпало бы с печатью PG; waitForInbox без options; два relay потребителя на одном outbox

## Root Cause

Контракты внутренних помощников заданы раньше их потребителей и не сверены; печатная форма политики не проверена по образцу tenant-isolation

## Solution

Полный тип queue; функции и строка в T11; OUTBOX_POLICY_PG через normalize(); waitForInbox с timeoutMs; fileParallelism: false у потребителя

## Prevention

Определять возвращаемые формы помощников по всем их потребителям в плане
