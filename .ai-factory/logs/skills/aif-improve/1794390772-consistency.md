# Проход +check: проба без каналов, документация экспортов, тесты E4 фикстуры, контракт txContextOf

**Date:** 2026-11-11 09:52
**Plan:** .ai-factory/plans/feature-e5-messaging
**Severity:** high

## Problem

В фазе 4 не было канала для теста пробы; ac-9-3-docs краснел до задачи 37; фикстура ломала ac-4-18 и ac-4-7; контракт txContextOf противоречил коду

## Root Cause

Фазы проверялись по своим тестам, без существующих проверок пакета, которые затрагивает изменение

## Solution

topologyReady без каналов true, канал probe в тесте; README/CHANGELOG в задачах-владельцах; явные правки ac-4-18 и ac-4-7; контракт без unbind

## Prevention

Для каждой фазы прогонять перечень существующих тестов пакета, которые читают затронутые артефакты
