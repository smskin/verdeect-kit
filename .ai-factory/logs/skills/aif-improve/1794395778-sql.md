# Итерация 4 +check: идентификатор схемы в шаблоне Drizzle

**Date:** 2026-11-11 11:16
**Plan:** .ai-factory/plans/feature-e5-messaging
**Severity:** high

## Problem

expectOutbox подставлял схему как параметр sql-шаблона — синтаксическая ошибка

## Root Cause

Не учтена семантика подстановок Drizzle sql

## Solution

sql.raw(quoteIdentifier(...)) для идентификаторов, result.rows

## Prevention

Идентификаторы в sql-шаблоне — только sql.raw/sql.identifier, по образцу kit-idempotency.module.ts
