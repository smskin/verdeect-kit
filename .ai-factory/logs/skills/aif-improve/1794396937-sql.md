# Итерация 5 +check: SQL relay и очистки

**Date:** 2026-11-11 11:35
**Plan:** .ai-factory/plans/feature-e5-messaging
**Severity:** high

## Problem

claimBatch сырой SQL (snake_case, timestamptz строкой); any(${ids}) раскрывается в список; идентификаторы markFailed/stats не определены; interval с параметром в литерале

## Root Cause

Запросы описаны как SQL-текст без учёта семантики шаблона Drizzle и маппинга строк

## Solution

Построитель Drizzle для claimBatch/markPublished/markFailed; ${t} в stats; make_interval в очистке

## Prevention

Запросы к таблицам пакета — построителем; сырой sql — только с объектами таблиц/колонок и sql.raw для идентификаторов
