# Итерация 6 +check: часть relay в AC-5.11, AfterCommitInReadOnlyError, type-тест Envelope

**Date:** 2026-11-11 11:46
**Plan:** .ai-factory/plans/feature-e5-messaging
**Severity:** high

## Problem

Ни один тест не проверял остановку relay (гонка STOPPED, нет markFailed); в задаче 19 INSERT стоял раньше afterCommit, поэтому обещанный AfterCommitInReadOnlyError недостижим; envelope.test-d.ts был обещан в рисках, но в задаче 8 его нет

## Root Cause

AC из нескольких частей сверялся по названию теста, а не по шагам; порядок шагов не сверен с текстом об ошибке; смягчение риска не перенесено в шаги задачи

## Solution

Задача 28 — случай relay через tcpProxy.freeze и сигнал onQuery; задача 19 — afterCommit до INSERT плюс случай в ac-5-1 (задача 22); задача 8 — шаг 5 envelope.test-d.ts; Traceability AC-5.11

## Prevention

Для каждой части AC искать проверяющий шаг; смягчения рисков оформлять шагами задач
