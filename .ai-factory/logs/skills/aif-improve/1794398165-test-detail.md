# Task 26: AC-5.9 — отдельный ReplicaConsumer на стенде dedupe none

**Date:** 2026-11-11 11:56
**Plan:** .ai-factory/plans/feature-e5-messaging
**Severity:** medium

## Problem

Случаи AC-5.9 не регистрировали onReplica: TestConsumer вызывает только on, канал реплики не создаётся — тест не может пройти; onReplica в TestConsumer привязал бы то же событие к основной очереди, и fail уходил бы в kit.retry -> kit.dlq, проверка «kit.dlq пуст» зависела бы от времени

## Root Cause

Общий тестовый провайдер описан для on, сценарий onReplica не сверен с условием создания канала реплики (задача 25, шаг 4.3)

## Solution

В задаче 26, шаг 4 — провайдер ReplicaConsumer (только onReplica, режимы ok/fail, счётчик), стенд subscriber {dedupe: 'none'}, проверки kit.dlq и kit по сигналу; строка Traceability AC-5.9 обновлена

## Prevention

Для каждого API регистрации (on/onReplica) проверять, что тестовый стенд действительно его вызывает и не задевает побочно другие очереди
