# Необязательный второй читатель workerScopeWith и умолчание VITEST_POOL_ID

**Date:** 2026-11-11 18:42
**Plan:** .ai-factory/plans/feature-e8-redis.md
**Severity:** medium

## Problem

Задача 11 добавляла второй читатель workerScopeWith без умолчания (три вызова в worker-scope.spec.ts с одним аргументом), умолчание VITEST_POOL_ID для redisPrefix не задано

## Root Cause

Сигнатура внутренней функции менялась без проверки существующих вызовов

## Solution

Второй параметр с умолчанием vitest.inject('kitRedisService'); VITEST_POOL_ID ?? '1' как rabbitmqOf

## Prevention

Перед изменением сигнатуры grep всех вызовов
