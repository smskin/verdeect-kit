# rc.7: точка внедрения KitLifecycle в KitMessagingModule

**Date:** 2026-11-13 11:40
**Plan:** .ai-factory/plans/fix-rc7-transition-findings.md
**Severity:** low

## Problem

4c утверждал, что KitLifecycle уже требуется через requireKitCore; модуль его не внедряет

## Root Cause

Допущение о DI не сверено с фабрикой KIT_RABBIT_CONNECTION

## Solution

Фабрика KIT_RABBIT_CONNECTION внедряет KitLifecycle (optional + requireKitCore) и передаёт функцию срока

## Prevention

Для новой зависимости модуля указывать конкретную фабрику и токен
