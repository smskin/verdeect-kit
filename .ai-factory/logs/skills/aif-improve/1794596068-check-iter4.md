# rc.8 iter4: объект и массив в тестах Content-Type повтора

**Date:** 2026-11-13 18:54
**Plan:** .ai-factory/plans/fix-rc8-transition-findings.md
**Severity:** low

## Problem

Задача 2a проверяла Content-Type повтора только для строки, числа, toJSON, text/csv и пустого ответа; строка таблицы комбинаций «простой объект / массив» и §3.3а «при любом теле» без теста

## Root Cause

Тесты 2a строились по перечню AC-4.14 (строка, число, toJSON), а не по таблице комбинаций плана

## Solution

В it.each 2a добавлены существующие маршруты /echo (объект) и /secret-list (массив), без новых маршрутов; Traceability обновлена

## Prevention

Сверять тесты с каждой строкой таблицы комбинаций Requirements Reconciliation, а не только с текстом AC
