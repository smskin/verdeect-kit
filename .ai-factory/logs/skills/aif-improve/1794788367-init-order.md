# Проверка соединения БД через общий промис Db

**Date:** 2026-11-16 00:19
**Plan:** .ai-factory/plans/fix-rc10-orchestrator-findings.md
**Severity:** medium

## Problem

Задача 6 полагалась на порядок onModuleInit KitDatabaseModule и KitIdempotencyModule

## Root Cause

Оба модуля подключает корневой модуль, KitIdempotencyModule не импортирует глобальный KitDatabaseModule — порядок не гарантирован

## Solution

Проверка — запоминаемый промис Db.connectionChecked(), его ждут оба onModuleInit

## Prevention

Не опираться на порядок хуков Nest между модулями одного уровня; общее предусловие — общий промис
