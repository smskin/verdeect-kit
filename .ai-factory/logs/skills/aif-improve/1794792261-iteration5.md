# Итерация 5 +check: сброс буфера логов Nest и источник итога журнала

**Date:** 2026-11-16 01:24
**Plan:** .ai-factory/plans/fix-rc10-orchestrator-findings.md
**Severity:** high

## Problem

autoFlushLogs false без flushLogs глушил все логи Nest Logger в сервисе и CLI; recordOutcome брал итог из finish() без причины и писал из skip(), общего с репликой

## Root Cause

Правка прошлой итерации не учла, что сброс буфера при успешном старте тоже завязан на autoFlushLogs; поток данных причины DLQ не прослежен

## Solution

Задача 6: app.flushLogs() в buildHttpApp и тест успешного пути; R7, R17, задачи 17–18: ctx.flushLogs() в CLI; задача 14: запись в handle() по действию decide()

## Prevention

Каждую правку опций фреймворка проверять на успешном и отказном путях; для журналов прослеживать, откуда берётся каждое поле
