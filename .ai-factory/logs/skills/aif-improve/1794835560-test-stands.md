# Стенды тестов AC-5.24 по фактическому API support

**Date:** 2026-11-16 13:26
**Plan:** .ai-factory/plans/fix-rc11-identity-findings.md
**Severity:** medium

## Problem

Задачи 7–9 ссылались на несуществующий workerScope().postgres.url, держали замок через pg_advisory_lock администратора и ломали права функции в общей БД kit через REVOKE

## Root Cause

План писался по образцу без сверки с test/support и без учёта процессной серии и проекта shared (isolate: false)

## Solution

Стенд — tcpProxy(appUrl()) + createTestDb({url, acquireTimeoutMs}); замок — runExclusive второго createTestDb с barrier; ошибка очистки идемпотентности — scratch-БД, логи через KIT_LOGGER, серия закрывается обычным стендом; переименован тест AC-9.5

## Prevention

Сверять стенды тестов с test/support; в shared-проекте не менять общую БД и учитывать процессное состояние
