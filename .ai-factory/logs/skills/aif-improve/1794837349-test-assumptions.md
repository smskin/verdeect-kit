# Тесты rc.11 по фактическому поведению кода и хелперов

**Date:** 2026-11-16 13:55
**Plan:** .ai-factory/plans/fix-rc11-identity-findings.md
**Severity:** medium

## Problem

Тест «outbox без политики» ломался после миграции 0009; RLS-вставку нельзя писать через withScratch; тест серии с одной ошибкой не ловит лишние captureError; один пробник AC-3.9 гонялся с очередью listen; run() после ошибки таблицы даёт ran:false

## Root Cause

План утверждал, что тесты останутся зелёными, но не пересчитал политики после миграции; хелперы и дедупликацию captureError не сверил с кодом

## Solution

Тест без политики дополнен DROP второй политики; стенд RLS — свой scratch и pg.Client; новые Error на вызов; второй пробник при ECONNRESET; TSDoc run() и различение замка по логам

## Prevention

Пересчитывать влияние новой схемы на существующие тесты; сверять хелперы и дедупликацию с кодом; в тестах сокетов учитывать очередь listen
