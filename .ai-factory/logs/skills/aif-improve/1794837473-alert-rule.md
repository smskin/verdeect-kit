# Правило VerdeectBackgroundFailures: конфликт метки job и образец выражения

**Date:** 2026-11-16 13:57
**Plan:** .ai-factory/plans/fix-rc11-identity-findings.md
**Severity:** medium

## Problem

Метка job конфликтует с меткой job задания сбора (exported_job); образец правила указан неверно; шапка порогов не обновлялась

## Root Cause

План перенёс имя метки из PRD и Orchestrator без учёта меток, которые добавляет сборщик метрик; образец выбран по соседству, а не по форме группировки

## Solution

В задачу 6 добавлен открытый вопрос пользователю до реализации; выражение — по виду VerdeectEventsDlq; в шапку добавлен :background_failures

## Prevention

Проверять имена меток на совпадение с метками сборщика (job, instance); образец правила выбирать по форме группировки
