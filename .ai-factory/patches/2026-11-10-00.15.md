# test-images пропускал чужие образы в compose; stop-grace-period не видел SHUTDOWN_TIMEOUT_MS базового compose

**Date:** 2026-11-10 00:15
**Files:** src/testing/repo-files.ts, src/testing/repo-conventions.ts, test/unit/testing/ac-1-8-repo-conventions.spec.ts, test/unit/testing/repo-files.spec.ts, README.md
**Severity:** high

## Problem

Ревью E1 (`review-test-images-compose-structured`, AC-1.8, §3.8). Правило `test-images` пропускало в compose `image: postgres:16`, `image: postgres` (без тега), `image: docker.io/library/postgres:16.1` и `image: ${PG_IMAGE:-postgres:16}`. Сервис мог закрепить другой мажор PostgreSQL, и общий тест репозитория оставался зелёным. Второе: переопределяющий compose со своим `stop_grace_period: 15s` сравнивался с умолчанием 10000, хотя `SHUTDOWN_TIMEOUT_MS: 20000` задан в базовом `compose.yml`. Нарушение 15000 ≤ 20000 терялось.

## Root Cause

Для значения `image:` использовался тот же текстовый поиск `imageTags()`, что и для свободного текста CI. Его эвристики там уместны, а для структурного значения неверны:
- тег без точки и буквы отбрасывается, чтобы `postgres:5432` в адресах не считался образом;
- образ без тега не находится вовсе;
- lookbehind `(?<![\w./@-])` отсекает префикс реестра.

Фикстура AC-1.8 проверяла только тег с точкой (`16.15-alpine3.24`), поэтому дыра не проявлялась. Для `stop_grace_period` откат к базовому `compose.yml` был, а для парного ключа `SHUTDOWN_TIMEOUT_MS` — нет: правило сравнивает два значения, а откат сделали только для одного.

## Solution

`parseImageRef(image)` в `repo-files.ts` разбирает значение как ссылку на образ:
- выполняет `expandDefaults`;
- отделяет дайджест `@…`;
- снимает префикс `docker.io/library/` и `docker.io/`;
- берёт тег после последнего `:` за последним `/`, чтобы порт реестра не считался тегом; без тега — `latest`;
- выставляет признак неразрешённой переменной.

Правило для compose (`composeImage`):
- репозиторий из `TEST_IMAGES` — требуется точный тег;
- переменная в теге — нарушение «тег не определён»;
- образы вне `TEST_IMAGES` и с неопределяемым репозиторием не проверяются.

`imageTags()` остался только для CI. `shutdownMs(service, base)` берёт ключ у того же сервиса базового `compose.yml`, если переопределение его не задаёт; умолчание 10000 — только если ключа нет ни там, ни там. Регрессия: сначала добавлены 6 случаев с нарушением, все падали; после правки зелёные вместе с 5 случаями без нарушения.

## Prevention

- Структурное значение (поле YAML или JSON) разбирать парсером значения, а не регулярным выражением для свободного текста. Эвристики против ложных срабатываний в тексте дают ложные пропуски в значении.
- Если правило сравнивает два значения, откат к базовому файлу делать для обоих сразу.
- Фикстуры правил покрывают граничные формы входа: тег из одних цифр, без тега, с префиксом реестра, с дайджестом, с интерполяцией, с портом реестра.
